# Study Planner

A simple, responsive study-task planner built with **HTML, CSS, and JavaScript**. It helps students add study tasks, mark them as completed, delete tasks, and see their progress.

## Features

- Add a task using the button or Enter key
- Mark tasks as completed
- Delete individual tasks
- Clear all completed tasks
- View total, completed, and remaining task counts
- Save tasks in the browser using Local Storage
- Responsive layout for mobile and desktop screens

## Technologies Used

- HTML5
- CSS3
- Vanilla JavaScript
- Browser Local Storage

## How to Run the Project

1. Download or clone this repository.
2. Open the project folder.
3. Double-click `index.html` to open it in your browser.

No installation or server is required.

## Project Structure

```text
study-planner/
├── index.html
├── style.css
├── script.js
└── README.md
```

## How It Works

- `index.html` contains the page structure.
- `style.css` controls the design and responsive layout.
- `script.js` handles task creation, completion, deletion, and Local Storage.
- `README.md` explains the project and how to use it.
